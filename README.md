# Tunnelhunt .github Repository

This repository contains organization-wide configurations, templates, and the public profile README for the **Tunnelhunt** organization on GitHub.

## Contents

* `profile/README.md` — The README displayed on the [Tunnelhunt organization profile](https://github.com/tunnelhunt).

## Repositories

Tunnelhunt maintains the following public repositories:

* [mcp](https://github.com/tunnelhunt/mcp) — Model Context Protocol (MCP) Server for AI-assisted development.
* [macos](https://github.com/tunnelhunt/macos) — Native macOS Menu Bar helper client.
* [desktop](https://github.com/tunnelhunt/desktop) — Cross-platform Tauri-based tray application.
